# About This Site

This portfolio turns a browser tab into a small macOS-style workspace. The apps are functional: browse project notes, search the launchpad, inspect links in Safari, or explore the fake filesystem in Terminal.

Built with React, TypeScript, Vite, UnoCSS, Zustand, Framer Motion, and `react-rnd`, then published with GitHub Pages.

The interface is adapted from [Renovamen/playground-macos](https://github.com/Renovamen/playground-macos) and [chu0jz013/chu0jz013.github.io](https://github.com/chu0jz013/chu0jz013.github.io).
