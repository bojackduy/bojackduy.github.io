# Appsfy — Mobile Design Intelligence

Appsfy helps teams collect app-store screenshots, browse mobile design references, organize screenshot sets, and create store-marketing assets with AI-assisted layouts.

## Contributions

- Built screenshot-set APIs and lifecycle operations.
- Added source-independent screenshot handling and option management.
- Implemented editor-frame hydration and product analytics events.
- Designed a validated AI layout-planning domain for structured creative generation.

## Stack

Kotlin, Micronaut, Exposed, PostgreSQL/PostGIS, Redis, S3-compatible storage, React 19, TypeScript, Vite, Tailwind, TanStack Query, and Konva.
